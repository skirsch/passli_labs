# Passli extension download

[Download version 0.1.213](passli-extension-0.1.213.zip) · [SHA-256](passli-extension-0.1.213.zip.sha256)

This is the pre-store Chrome/Edge extension. Download the ZIP and extract it to
a permanent folder. Open `chrome://extensions` (Edge: `edge://extensions`), enable
**Developer mode**, choose **Load unpacked**, and select the extracted folder
containing `manifest.json`. Sign in to Passli to connect your account.

To update, extract the new download into that same folder, click **Reload** on
the extension card, and refresh open site tabs. Updates are manual until the
extension is available through the store. Keep the extracted folder on disk.

The package excludes development scripts, tests, private demo configuration and
the default local demo signing key. Third-party notices remain in vendor bundles.
See [release metadata](release.json) for source commit and checksum.
